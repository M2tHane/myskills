# 采购协同（精简版）

> 完整需求见 [PRD.md](./PRD.md)。

**做什么**：给 6 人的采购部做一个内网系统，采购员登记采购单，主管在线审批，供应商资料集中维护。

**两个角色**：采购员（看供应商、开采购单、撤回自己的单）；采购主管（另外能维护供应商、审批采购单、用审批工作台）。

**8 个页面**：概览、采购单列表、采购单详情、新建采购单、供应商列表、供应商详情、新建 / 编辑供应商、审批工作台（只有主管）。

**关键规则**：
- 采购单流转：草稿 → 待审批 → 已通过 / 已驳回；创建人能撤回待审批的单。
- 金额超过 ¥50,000.00 的采购单通过时要二次确认，不能批量通过。
- 只有主管能新建、编辑、停用供应商；已停用的供应商不能再下单。

**不做**：到货登记与对账、财务对接（二期）；供应商门户。
